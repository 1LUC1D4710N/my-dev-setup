## 🐍 Python Development

### ms-python.python
**Python Extension Pack** - The core Python extension for VS Code
- **Features:**
  - IntelliSense (code completion)
  - Linting and formatting
  - Debugging support
  - Jupyter Notebook support
  - Environment management
- **Why It's Essential:** Foundation for all Python development in VS Code

### ms-python.vscode-pylance
**Pylance** - Fast, feature-rich language support for Python
- **Features:**
  - Type checking
  - Auto-imports
  - Code navigation
  - Semantic highlighting
- **Why It's Essential:** Provides advanced IntelliSense and type information

### ms-python.debugpy
**Python Debugger** - Debugging support for Python
- **Features:**
  - Breakpoints and stepping
  - Variable inspection
  - Call stack analysis
  - Remote debugging
- **Why It's Essential:** Professional debugging capabilities

### donjayamanne.python-environment-manager
**Python Environment Manager** - Manage Python environments easily
- **Features:**
  - View all Python environments
  - Create virtual environments
  - Switch between environments
  - Install packages
- **Why It's Essential:** Simplifies Python environment management

### ms-python.black-formatter
**Black Formatter** - Opinionated Python code formatter
- **Features:**
  - Consistent code formatting
  - Auto-format on save
  - PEP 8 compliant
- **Why It's Essential:** Maintains consistent code style across projects

### charliermarsh.ruff
**Ruff** - Extremely fast Python linter
- **Features:**
  - Fast linting (10-100x faster than alternatives)
  - Replaces Flake8, isort, and more
  - Auto-fix capabilities
- **Why It's Essential:** Catches errors and enforces best practices

## 🚀 Installation

### Automatic Installation (Recommended)

Use the provided script to install all extensions at once:

```powershell
.\install-vscode-extensions.ps1
```

### Manual Installation

Install individual extensions via VS Code:
1. Press `Ctrl+Shift+X` to open Extensions view
2. Search for the extension ID (e.g., "ms-python.python")
3. Click "Install"

### Command Line Installation

Install a specific extension:
```powershell
code --install-extension <extension-id>
```

Example:
```powershell
code --install-extension ms-python.python
```

## ⚙️ Recommended Settings

Add these to your `settings.json` for optimal experience:

```json
{
  "python.defaultInterpreterPath": "python",
  "python.linting.enabled": true,
  "python.linting.pylintEnabled": false,
  "python.linting.ruffEnabled": true,
  "python.formatting.provider": "black",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.organizeImports": true
  },
  "github.copilot.enable": {
    "*": true,
    "python": true,
    "markdown": true
  },
  "errorLens.enabled": true,
  "gitlens.codeLens.enabled": true
}
```

## 🔄 Updating Extensions

### Update All Extensions
1. Press `Ctrl+Shift+X`
2. Click "..." in Extensions view
3. Select "Update All Extensions"

### Auto-Update
Enable in Settings: `Extensions: Auto Update` → `all`
